💻 3. How the Code Works

To achieve this, we do not need complex JavaScript intervals. Modern CSS handles this perfectly, utilizing hardware acceleration for smoother frame rates. Here is the core logic: 

/* Step 1: Create the animation timeline */
@keyframes spin-continuous {
    0%   { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}

/* Step 2: Apply the timeline to the image */
.spinning-image {
    /* spin-continuous runs for 8 seconds, linearly (constant speed), forever */
    animation: spin-continuous 8s linear infinite;
}

/* Step 3: Pause the animation when the user hovers over it */
.spinning-image:hover {
    /* This overrides the running state, freezing the image in place */
    animation-play-state: paused;
}
