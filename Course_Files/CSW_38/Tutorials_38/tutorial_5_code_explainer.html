Responsive Design Fundamentals

Welcome class! Before we dive into advanced HTML5 Canvas animations, we must ensure our web pages are fully responsive. A responsive design automatically adapts its layout, images, and navigation to look great on any device—whether it is a tiny smartphone, a mid-sized tablet, or a massive desktop monitor.

To achieve this, we rely on three core pillars of modern web design: The Viewport Meta Tag to control scaling, CSS Flexbox to create fluid layouts, and CSS @media queries to apply specific styles based on screen width. Let's examine the code for each.

1️⃣ The Viewport Meta Tag

Mobile browsers try to display full desktop pages by "zooming out" so the whole page fits on the screen. This makes text unreadable. We fix this by placing the viewport <meta> tag inside our HTML <head>. 

<!-- 
  The Viewport Tag: 
  Place this inside your <head> element.
-->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<!-- 
  CODE EXPLANATION:
  - name="viewport": Tells the browser we are configuring the visual viewport.
  - width=device-width: Instructs the page to match the screen's width in device-independent pixels.
  - initial-scale=1.0: Sets the initial zoom level when the page is first loaded. It prevents the browser from automatically zooming out.
-->

2️⃣ CSS Flexbox (Flexible Box Layout)

Flexbox is a CSS layout module designed to automatically align and distribute space among items in a container, even when their size is unknown or dynamic. It is perfect for navigation menus and responsive photo galleries. 

/* 
 * FLEXBOX STYLES:
 * Apply these rules to a container (like a <nav> or <div>) to turn it into a flexbox.
 */
.flex-container {
    /* 1. Turns on the flexbox engine for this container */
    display: flex;

    /* 2. flex-direction determines the main axis. 
          'row' places items side-by-side (left to right).
          'column' places them top-to-bottom (great for mobile!). */
    flex-direction: row;

    /* 3. flex-wrap allows items to push to the next line if they run out of space.
          If set to 'nowrap', they will shrink or overflow. */
    flex-wrap: wrap;

    /* 4. justify-content aligns items along the MAIN axis (horizontal in a row).
          'space-between' puts equal space between items, pushing the first and last to the edges.
          Other options: center, flex-start, flex-end, space-around. */
    justify-content: space-between;

    /* 5. align-items aligns items along the CROSS axis (vertical in a row).
          'center' perfectly vertically centers the items within the container. */
    align-items: center;
}

3️⃣ CSS @media Queries (Mobile, Tablet, Desktop)

Media queries allow us to apply CSS conditionally based on the screen's width. We use a "Mobile First" approach: we write the mobile styles first (outside any query), and then use min-width queries to progressively enhance the layout for wider screens. 

/* 
 * STEP 1: MOBILE FIRST (Default Styles)
 * These styles apply to ALL devices automatically. 
 * Since mobile screens are narrow, we stack elements vertically.
 */
body {
    font-size: 1rem;
    background-color: #111;
}

.gallery-item {
    width: 100%; /* Take up the full width of the phone screen */
    margin-bottom: 1rem;
}

/* 
 * STEP 2: TABLET DEVICES (Minimum width of 481px)
 * When the screen reaches 481px or wider, the browser reads inside this block.
 * These rules override the mobile defaults above.
 */
@media only screen and (min-width: 481px) {
    
    .gallery-item {
        /* On tablets, we have more room. Let's make items take up half the screen. */
        width: 48%; 
        float: left;
        margin-right: 2%;
    }
}

/* 
 * STEP 3: DESKTOP DEVICES (Minimum width of 769px)
 * When the screen reaches 769px or wider, the browser reads inside this block.
 * These rules override BOTH the mobile and tablet styles.
 */
@media only screen and (min-width: 769px) {
    
    body {
        /* Increase the base font size for large monitors */
        font-size: 1.2rem; 
    }

    .gallery-item {
        /* On desktops, we have lots of room. Let's fit 3 items across! */
        width: 31%; 
        margin-right: 2%;
    }
}
