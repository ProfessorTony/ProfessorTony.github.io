JavaScript Animation Basics (in Canvas)

Welcome! Animation on a webpage seems complex, but it's just one simple trick repeated very fast: Clear, Update, and Draw. Imagine a flipbook. You draw a picture, then on the next page, you draw it in a slightly different spot. When you flip the pages, it looks like it's moving.

In JavaScript, we do this with an "animation loop." We'll use a special function called requestAnimationFrame(). This is the browser's optimized way to run animation code. It's much smoother and more efficient than using setInterval (like in our clock example).

The Animation Loop:

  1. Clear the Canvas: We wipe the canvas clean with ctx.clearRect(). This erases the last frame.
  2. Update Coordinates: We do some math to figure out the *new* position for our shape (e.g., x = x + 1).
  3. Draw the Shape: We draw the shape at its new position (e.g., ctx.fillRect(...)).
  4. Repeat: We tell the browser to run this loop again as soon as it's ready for the next frame using requestAnimationFrame().
