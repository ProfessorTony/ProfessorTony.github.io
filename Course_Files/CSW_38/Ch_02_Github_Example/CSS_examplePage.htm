Welcome to Web Animation

In this course, we bridge the gap between static web pages and interactive experiences. To do this effectively, we must understand how HTML, CSS, and JavaScript work together.

HTML provides the structure, CSS provides the style, and JavaScript provides the logic and animation.

The Document Object Model (DOM)

Before we can animate an element, JavaScript needs a way to find it. The browser creates a representation of your HTML called the Document Object Model, or DOM.

Think of the DOM as a tree structure where every HTML tag is a branch or a leaf. JavaScript can climb this tree to read, change, add, or delete elements.

The HTML5 Canvas

While we can animate standard HTML elements (like `div`s or `img`s) using CSS transitions or JavaScript, the HTML5 <canvas> element gives us a dedicated drawing surface.

It is essentially a blank bitmap area. We use JavaScript to draw shapes, lines, and images pixel by pixel.
